# Saunojen Vuokraus - Task L

## Kuvaus
Saunavuokraussivusto, joka koostuu kolmesta sivusta.

## Sivurakenne
- **index.html** - Landing page tarjouksella ja esittelyllä
- **catalog.html** - Kolme saunaa kuvineen ja tiedoilla
- **order.html** - Varauslomake

## Tekniikat
- HTML5 semanttiset elementit
- CSS (yhtenäinen tyylitiedosto)
- JavaScript (scroll progress, lomakevalidointi)
- Responsiivinen suunnittelu

## Yhtenäisyys
- Sama navigaatio kaikilla sivuilla
- Yhtenäinen värimaailma (ruskeat sävyt)
- Sama typografia (Georgia serif)
- Yhteiset button-tyylit ja animaatiot
